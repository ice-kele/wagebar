# WageBar · 开发路线图

## 当前版本：v0.1.0 (MVP)

### MVP 铁三角
1. **薪资配置 + 实时赚钱进度条**

## 版本规划原则

1. **MVP 先行**：先做最有传播力的"赚钱进度条 + 加班费"，验证用户兴趣
2. **两周一个迭代**：保持节奏，小步快跑
3. **开源优先**：每个版本都可用、可编译、可贡献
4. **隐私第一**：所有版本默认本地存储，同步功能永远可选
