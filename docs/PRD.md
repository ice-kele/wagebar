# WageBar · 打工进度条 — 产品需求文档 (PRD)

> 版本：v0.1 | 最后更新：2025-07-14

## 一、产品定位

### 一句话描述
把用户的真实月薪变成实时游戏进度的个人效率工具。

### 目标用户
- 月薪制职场打工人群（互联网、传统行业、外企等）
- 关心自己"时间值多少钱"的人
- 想要量化工作价值、追踪加班收入的打工人

### 核心价值主张
1. **薪资感知**：让打工的每一秒都有明确价格，对抗"时间无感"
2. **加班维权**：自动记录加班时长并按法定倍率计算应得报酬
3. **游戏化激励**：把枯燥的日常工作变成有进度、有成就的升级体验
4. **数据自主**：薪资数据完全本地化，开源可审计

## 二、核心功能模块

### 模块一：薪资引擎 (Salary Engine)

#### 1.1 薪资配置
用户输入基础薪资信息，系统自动计算衍生数据。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 月薪 | number | - | 税前月薪（元） |
| 计薪天数 | number | 21.75 | 法定月计薪天数 |
| 日工时 | number | 8 | 每日标准工时 |
| 工作日加班倍率 | float | 1.5 | 工作日延时加班 |
| 休息日加班倍率 | float | 2.0 | 周末加班 |
| 法定假日加班倍率 | float | 3.0 | 国家法定节假日 |
| 午休时长 | number | 1 | 扣除的午休时间（小时） |

#### 1.2 自动计算
```
日薪 = 月薪 / 计薪天数
时薪 = 日薪 / 日工时
秒薪 = 时薪 / 3600
工作日加班时薪 = 时薪 × 1.5
休息日加班时薪 = 时薪 × 2.0
法定假日加班时薪 = 时薪 × 3.0
```

#### 1.3 实时赚钱进度
- 首页核心组件，每秒更新
- 显示当日已赚金额 / 当日应赚总额
- 进度条可视化当日工作进度
- 下班后进入加班模式，进度条变金色

### 模块二：打卡系统 (Attendance)

#### 2.1 打卡模式

**固定制**
- 用户配置固定上下班时间（如 09:00-18:00）
- 系统在上班前 10 分钟推送打卡提醒
- 下班时间到达后推送下班提醒

**弹性制**
- 用户配置弹性窗口（如 09:00-10:00 可上班）
- 满标准工时后可打卡下班
- 系统根据实际上班时间推算下班时间

#### 2.2 加班自动识别
```
触发条件：下班时间后用户未打卡下班
处理逻辑：
  1. 下班时间 +30min → 推送"检测到加班，是否继续？"
  2. 用户确认 → 进入加班计费模式
  3. 每满 1 小时 → 推送"已加班 Xh，赚了 ¥XXX"
  4. 达到加班上限（默认 4h）→ 推送"注意休息"
  5. 用户打卡下班 → 结算当日加班费
```

#### 2.3 忘打卡兜底
- 连续 24h 未打卡 → 自动标记为"请假/缺勤"
- 提供手动补卡入口
- 补卡仅能选择"正常"或"加班 N 小时"

#### 2.4 推送策略
| 时间点 | 推送内容 | 场景 |
|--------|---------|------|
| 上班前 10min | "该打工了，点击打卡" | 到了上班时间 |
| 上班后 30min（未打卡） | "迟到提醒，已迟到 Xmin" | 忘记打卡 |
| 下班时间 | "下班时间到，打卡回家" | 正常下班 |
| 下班后 30min（未打卡） | "检测到加班，确认？" | 可能加班 |
| 加班每小时 | "已加班 Xh，赚了 ¥XXX" | 加班中 |
| 深夜 23:00 | "明天还得搬砖，早点休息" | 加班过晚 |

### 模块三：游戏化系统 (Gamification)

#### 3.1 等级体系
基于累计已赚金额，而非虚拟货币。

| 等级 | 名称 | 累计金额 |
|------|------|---------|
| Lv.1 | 职场萌新 | ¥0 |
| Lv.2 | 初级搬砖工 | ¥3,000 |
| Lv.3 | 资深搬砖工 | ¥10,000 |
| Lv.4 | 打工达人 | ¥30,000 |
| Lv.5 | 职场老手 | ¥60,000 |
| Lv.6 | 资深专家 | ¥100,000 |
| Lv.7 | 打工皇帝 | ¥200,000 |
| Lv.8 | 财务自由预备军 | ¥500,000 |

#### 3.2 成就系统
采用**快照重算模式**（参考 NiniMenu 架构）：每次触发条件时重新计算全部成就状态，幂等写入，避免事件状态机的复杂性和漏触发问题。

**预设成就（MVP 10 个）**
| 成就 | 条件 | 图标 |
|------|------|------|
| 打工魂觉醒 | 连续打卡 7 天 | 🏆 |
| 月度全勤 | 单月无迟到无缺勤 | 🎯 |
| 卷王之王 | 单月加班 > 20h | 👑 |
| 反卷先锋 | 连续 5 天准时下班 | ✊ |
| 时薪玩家 | 时薪突破 ¥100/h | 💎 |
| 十万哥 | 累计赚够 ¥100,000 | 🎊 |
| 周末自由人 | 连续 4 周周末零加班 | 🏖️ |
| 打工百日 | 累计使用 100 天 | 💯 |
| 加班达人 | 累计加班 > 100h | 🔥 |
| 生活家 | 单周工作 ≤ 40h | 🌿 |

#### 3.3 周/月战报
- 每周日自动生成周报
- 展示：总工时、加班时长、已赚金额、成就解锁
- 可生成分享卡片（适合社交媒体传播）

## 三、数据模型

### 核心实体

```
UserProfile（用户配置）
├── salary_config: SalaryConfig（薪资配置）
├── attendance_config: AttendanceConfig（打卡配置）
├── level: int（当前等级）
└── total_earned: decimal（累计已赚）

AttendanceRecord（打卡记录）
├── date: DateTime
├── clock_in: DateTime?
├── clock_out: DateTime?
├── overtime_hours: decimal
├── overtime_pay: decimal
└── status: enum(normal, late, absent, leave)

Achievement（成就）
├── id: string
├── name: string
├── description: string
├── condition: Expression
├── unlocked_at: DateTime?
└── icon: string

Task（任务，v0.2）
├── title: string
├── deadline: DateTime?
├── status: enum(todo, doing, done)
├── estimated_hours: decimal?
└── actual_hours: decimal?
```

## 四、非功能性需求

### 性能
- 首页赚钱进度条刷新：每秒一次，CPU < 1%
- 应用冷启动：< 2 秒
- 数据库操作：< 100ms

### 隐私与安全
- 薪资数据本地 AES 加密存储
- 无强制注册/登录（本地优先）
- 可选的加密同步服务

### 可访问性
- 支持深色模式
- 支持系统字体缩放
- 中英双语
