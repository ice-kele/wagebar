## 🎯 这是什么？

WageBar 是一个面向打工人的**个人效率 + 财务 + 游戏化**工具。

输入你的月薪，它会：

- ⏱️ **实时显示你已经赚了多少钱** — 每一秒都在跳动，打工的每一秒都有价
- 📝 **打卡 + 自动计算加班费** — 下班没打卡？自动算加班，按法定倍率计薪
- 🎮 **工作进度游戏化** — 等级、成就、周报，把搬砖变成打怪升级
- 📊 **财务分析** — 月度收入、加班占比、时薪趋势，用数据看清你的时间价值
- 🔒 **数据完全自主** — 本地优先存储，开源可审计，你的薪资数据只属于你

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────────┐
│              Flutter 前端（六端共用）              │
│  ┌──────────┬──────────┬──────────┬───────────┐ │
│  │ 薪资引擎  │ 打卡模块  │ 游戏化系统 │ 财务分析  │ │
│  └──────────┴──────────┴──────────┴───────────┘ │
├─────────────────────────────────────────────────┤
│           本地存储层 (SQLite / Hive)              │
│     薪资数据加密存储，零云依赖，完全离线可用        │
├─────────────────────────────────────────────────┤
│         可选：自托管同步服务 (Go)                  │
│     多设备数据同步，端到端加密                     │
└─────────────────────────────────────────────────┘
```

**技术选型理由**：
- **Flutter**：一套代码覆盖六端，UI 一致性 + 原生性能
- **本地优先**：薪资是敏感数据，默认全本地存储，零云依赖
- **Go 同步服务**：可选的多设备同步，轻量高效

详见 [技术架构文档](docs/ARCHITECTURE.md)
